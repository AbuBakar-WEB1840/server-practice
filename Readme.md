# User Data Manager
Project with forntend and backend to strengthen my knowledge
* It demonstrate how to send data from frontend to backend and receive the backend response
* Attach mongodb with backend
* Client send the request, Javascript handle the request and send it to server. Server process 
request and fetch or insert data to mongodb and send response to client. That response is also 
handle by js function

**Frontend:** HTML, JavaScript (Fetch API)
**Backend:** Python (Flask)
**Database:** MongoDB (or any other)


## Project Structure
* /homepage                    <!-- It has four button -->
    - New User
    - Update User
    - Delete User
    - Read User

* /new_user                     <!-- To register new user and store it in data base-->
* /update_user                  <!-- To update user data -->
* /delete_user                  <!-- To delete user-->
* /read_user                    <!-- To read user -->
